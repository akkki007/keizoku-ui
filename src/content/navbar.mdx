# Navbar

A fixed header whose hairline runs the full width of the viewport, drops 24px
through the centre slice and comes back up — one unbroken rule interrupted by
a control. Drawn as SVG strokes rather than borders, because a border cannot
bend.

Toggle the theme in the bar above — one component, both modes. It carries no
colours of its own: `background`, `foreground`, `muted-foreground` and `border`
come from whatever project it is installed into.

## Usage

<CodeBlock language="tsx" title="src/app/layout.tsx" code={`import { Navbar } from "@/components/block/navbar"

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <Navbar
        brand="継続"
        brandHref="/"
        leftLinks={[{ label: "Components", href: "/docs" }]}
        rightLinks={[{ label: "Docs", href: "/docs" }]}
      />
      {/* The bar is fixed at 56px; offset whatever follows it. */}
      <main className="pt-14">{children}</main>
    </>
  )
}`} />

### Custom actions

`actions` replaces the trailing controls. Anything passed here also renders in
the mobile row, where it balances the menu button and keeps the brand optically
centred.

<CodeBlock language="tsx" code={`<Navbar
  rightLinks={[{ label: "Docs", href: "/docs" }]}
  actions={
    <a
      href="/login"
      className="rounded-full border border-border px-4 py-1.5 text-[13px] text-muted-foreground transition-colors duration-[var(--k-dur-1)] hover:text-foreground"
    >
      Sign in
    </a>
  }
/>`} />

Pass `actions={null}` to remove them, and the divider with them.

## Notes

- **Height is 56px**, with the rails 20px deep and the notch dropping to the hairline at y≈54. Offset the page by `pt-14` and the first element sits on the rule rather than under it.
- **The notch is a real cutout, not a drawn line.** Nothing fills the box behind the rails, so the page shows through the band either side of the notch and scrolls past it. Give the header a background of its own if you want it sealed — you lose the cut.
- **The mobile panel is uncovered, not faded** — a `clip-path` inset travelling from the top edge over `--k-dur-3`. Under `prefers-reduced-motion` it becomes an opacity change with no travel.
- **Escape closes the panel** and returns focus to the menu button.
- **Hover is a 120ms ink change.** No underline slide, no scale. If you want movement in the bar, put it in the rule, not in the links.
