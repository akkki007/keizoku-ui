# Ruled Section

The primitive the rest of the library hangs off. One dashed hairline across the
top, a label gutter on the left carrying the section name in mono, an index
rail on the right, and the content column between them.

<ComponentPreview
  label="Ruled Section"
  component={<RuledSectionDemo />}
  previewClassName="!p-0"
  code={`import { FramedCard, RuledSection } from "@/components/ui/ruled-section"

export function Demo() {
  return (
    <RuledSection label="Components" index="01 / 07">
      <FramedCard>
        <h3 className="text-xl font-medium text-foreground">The grid is the ornament</h3>
      </FramedCard>
    </RuledSection>
  )
}`}
/>

The rule is a repeating gradient, not a dashed border. A border's dashes
stretch to fit the element, so two sections of different widths would end up
with two different dash patterns — which breaks the one rule this library
cannot afford to break.

## Usage

### A control on the rule

`action` centres a control on the top rule and covers the dash run behind it.
This is the house structural move — an interrupted rule proves the line is a
drawn object rather than a border — and it is the one licensed exception to the
unbroken grid.

<CodeBlock language="tsx" code={`<RuledSection
  label="Components"
  index="01 / 07"
  action={
    <a
      href="/docs"
      className="rounded-full border border-border px-4 py-1.5 font-mono text-[11px] uppercase tracking-[0.14em] text-muted-foreground"
    >
      View all
    </a>
  }
>
  {children}
</RuledSection>`} />

Use it on at most one section per view. Two interruptions read as a pattern,
and a pattern of interruptions is just a broken rule.

### Stacking sections

Each section draws its own top rule, so a stack shares one continuous grid with
no doubled lines. Only the last one closes.

<CodeBlock language="tsx" code={`<>
  <RuledSection label="Overview" index="01 / 03">…</RuledSection>
  <RuledSection label="Components" index="02 / 03">…</RuledSection>
  <RuledSection label="Templates" index="03 / 03" closed>…</RuledSection>
</>`} />

### The other exports

<CodeBlock language="tsx" code={`import { FramedCard, MetaLabel, Rule } from "@/components/ui/ruled-section"

// The house hairline: 1px, 4/4 dash, one colour. Use this rather than a
// border anywhere you need a divider.
<Rule />

// Uppercase letter-spaced mono — the label-gutter voice, shared by every
// piece of meta text in the library.
<MetaLabel>Updated 2026-09-20</MetaLabel>

// A 4px inset child inside a 6px surface. Depth without a shadow.
<FramedCard contentClassName="p-6">{children}</FramedCard>`} />

## Notes

- **Gutters are 96px** and held with no deviation on desktop. Below `md` they collapse and the label moves above the content, because a 16px gutter cannot carry letter-spaced mono.
- **Rules replace separators between sections, never spacing within them.** Inside a cell, group with space and keep the 2× gap ratio. The moment rules start dividing content *within* a section, the page is clutter.
- **The index rail is meta, not navigation.** It takes counts and coordinates. If it needs to be clickable, it belongs in `action`.
