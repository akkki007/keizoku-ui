# Socials

A single rounded rail holding grouped brand marks, split by the house hairline.
Hovering a mark pushes its neighbours aside and raises its name above the rail.

The spread is built from layout, not from a transform. The hovered item takes
extra horizontal margin and the flex row pushes everything else aside; because
the rail is centred and grows symmetrically, the mark under the cursor stays
where it is while the rest of the row moves away from it. A scale-up would grow
the icon *under* the pointer and risk pulling the target out from beneath it.
Nothing blurs, springs or shrinks.

GSAP drives both the spread and the label, on one timeline per mark. It reads
`--k-dur-2` and `--k-ease-travel` off the element rather than hardcoding
either, so the rail retunes when the motion scale does — and the reduced-motion
floor that ships with the component collapses the duration for free.
`--k-ease-travel` is a cubic-bezier, so `CustomEase` reproduces it exactly
instead of settling for the nearest `power` ease.

## Glass

The same rail on a translucent surface. It only earns its keep over something
worth refracting — photography, a gradient, content scrolling underneath. Over
a flat panel it reads as reduced opacity, not as a pane.

## Usage

### Groups and the rule

Each array in `groups` is drawn as a run of marks, with a hairline between one
run and the next. Pass a single group for an undivided rail.

<CodeBlock language="tsx" code={`<Socials
  label="Find me on"
  groups={[
    [linkedin, telegram, email],   // contact
    [ddb, freelance, aiDev, fiverr, x],  // work
  ]}
/>`} />

### Icons

`icon` is a `ReactNode`, not a URL, so the mark can be anything — a raster
logo, an inline SVG, a framework image component. Whatever you pass is sized
to fill a square box and clipped to the rail's radius, so square and
pre-rounded artwork sit together without looking mismatched.

<CodeBlock language="tsx" code={`import Image from "next/image"

const item = {
  label: "Fiverr",
  href: "https://fiverr.com",
  icon: <Image src="/socials/fiverr.png" alt="" width={92} height={92} />,
}

// or an icon component
const github = {
  label: "GitHub",
  href: "https://github.com",
  icon: <GithubIcon />,
}`} />

### Sizing

Every measurement derives from one variable, so the rail scales as a unit.
`--rail-icon` defaults to `clamp(40px, 5vw, 56px)` and needs no breakpoints —
56px on a wide screen, 40px on a phone. Pass `size` to pin it, or override the
variable for a rail that runs larger than the default.

<CodeBlock language="tsx" code={`<Socials size={44} groups={groups} />

// or override the variable, for a rail that runs larger
<Socials
  style={{ "--rail-icon": "clamp(56px, 7vw, 92px)" } as React.CSSProperties}
  groups={groups}
/>`} />

Below the point where the rail stops fitting, it scrolls sideways rather than
shrinking its marks further. The scroll container carries the label's headroom,
so a raised label is never clipped.

## Notes

- **The label is decoration; the link carries the name.** Each mark's accessible name comes from a visually hidden span, and the raised label is `aria-hidden` — so a screen reader hears one link per mark rather than the name twice.
- **Keyboard gets the same behaviour as the pointer.** `focus-within` spreads the row and `focus-visible` raises the label, so tabbing through the rail reads the same way hovering it does.
- **Marks never shrink below 40px.** When the rail no longer fits, it scrolls rather than shrinking further.
- **Touch taps do not open a label.** The spread is driven by pointer events and ignores `pointerType: "touch"`, so a tap navigates instead of leaving a mark stuck open.
- **Glass is a surface, not a motion channel.** `backdrop-filter` on a genuinely translucent pane is permitted here; blur as a way of *moving* something is still refused. See [the thesis](https://github.com/akkki007/keizoku-ui/blob/main/docs/KEIZOKU.md).
- **`external` defaults on for absolute URLs** and adds `rel="noreferrer noopener"`. Relative paths, `mailto:` and `tel:` stay in place.
- **Under `prefers-reduced-motion`** the spread and the label resolve instantly. GSAP reads its duration from `--k-dur-2`, which the shipped floor collapses to 0.01ms, so the states still change but nothing travels.
